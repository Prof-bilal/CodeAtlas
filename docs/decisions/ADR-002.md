# ADR-002: Orchestrate existing AI CLIs — do not reimplement their internals

Status: Proposed
Date: 2026-08-08

## Context

CodeAtlas Direction B is a "Unified AI CLI Orchestrator": the user types
`atlas /claude fix this`, and CodeAtlas routes to a coding agent. A tempting
but wrong approach is to reimplement each agent's reasoning (prompt loops, tool
routing, context management) inside CodeAtlas, duplicating Claude CLI, Gemini
CLI, Codex, and OpenCode.

## Decision

- CodeAtlas **launches and supervises the already-installed external CLI** for
  each agent (via an `AgentAdapter` + process manager), passing the user's
  prompt as arguments, in a terminal/session.
- CodeAtlas owns: agent discovery, spawning, lifecycle, exit codes, timeouts,
  environment config, and (eventually) concurrent sessions.
- CodeAtlas does **not** own the agent's reasoning. See
  [AGENT_ORCHESTRATOR.md](../AGENT_ORCHESTRATOR.md).

## Alternatives

- **Full in-process reimplementation of each agent.** Rejected: re-implements
  large, fast-moving, per-vendor surfaces; breaks the "orchestrate, don't
  recreate" principle; bloats the dependency surface and maintenance burden.
- **Only route via one vendor's API.** Rejected: couples the orchestrator to a
  single provider, violating Provider Agnosticism on the orchestrator side.

## Consequences

- **Positive:** small, stable orchestrator; each agent's capabilities/fixes
  arrive by upgrading the external CLI; consistent UX across agents.
- **Negative:** depends on a CLI being installed for each agent — hence the
  planned availability detection (`atlas doctor`, `atlas agents`) and clear
  "not installed" errors; behavior differences between CLI versions are the
  agent's, not ours.
- **Security:** process spawning is the highest-risk surface — ADR adds Security
  Policy obligations ([SECURITY.md](../SECURITY.md) §3): array args, no shell
  strings, binary-from-PATH, timeouts, and no AI-generated command execution.

## Follow-ups (Phase 4 of [ROADMAP.md](../ROADMAP.md))

Agent discovery, adapters (`/claude`, `/gemini`, `/codex`, `/opencode`,
`/deepseek`), process manager, terminal/session handling.
