# ADR-001: `@atlas/context` — deterministic rank-and-assemble behind `ContextBuilderPort`

Status: Accepted; superseded by implementation (2026-08-14)
Date: 2026-08-08

## Context

The Context Engine pipeline (scan → parse → graph → store) is implemented and
tested. `@atlas/context` (`ContextBuilderService`, the rank-and-assemble step
that picks the most relevant context to send to an LLM) originally threw
`ComingSoonError` from both of its methods. A naive reader could mistake this
for an unfinished bug and "fix" it by deleting the port, implementing ranking
hastily, or wiring an LLM into the ranking.

## Decision

- Keep `ContextBuilderPort` as the contract and `ContextBuilderService` as its
  implementation.
- Ranking/assembly ships **deterministically** — aligned with the
  **"Deterministic Before AI"** principle ([PRINCIPLES.md](../PRINCIPLES.md)) —
  and is wired into the default SDK `Container`.
- The service is first-class: it is composed via
  `new ContextBuilderService({ search, db: contextDb })` in
  `packages/sdk/src/container.ts`, and its tests assert real ranked output.

## Implementation (2026-08-14)

- `build(query, limit?)` refreshes the search index, runs a ranked query through
  `SearchPort`, and maps each hit that carries a resolvable source path to a
  `ContextItem { source, content, score }`, deduplicating by source file and
  keeping the highest score.
- `sourceFile(path)` returns a single file's content as one `ContextItem`
  (`score: 1`) when the path is indexed, else `ok(undefined)`.
- Both methods return `Result` (`ok`/`fail`); search refresh failures propagate.
- No AI is involved: this is the deterministic rank step. The SDK's
  `getRelevantContext` remains an independent, richer deterministic assembly.

## Alternatives

- **Delete the port entirely.** Rejected: the port is the plugin seam and future
  proof; removing it would propagate throwaway changes across `core`, `sdk`, and
  the CLI.
- **Implement an AI-gated ranker.** Rejected: ranking must remain
  AI-optional; the deterministic ranker ships first.

## Consequences

- Consumers of `getContext()` from a default `Container` get ranked, source-file
  context items instead of an error.
- The interface was stable throughout, so the implementation landed additively
  with no breaking changes.
- Docs (CURRENT_STATE, FEATURE_STATUS, CONTEXT, this ADR) reflect the shipped
  deterministic ranker so AI agents don't misreport it as a stub.
