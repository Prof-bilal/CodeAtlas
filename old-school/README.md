# old-school/ — Historical CodeAtlas Archive

This directory contains historical CodeAtlas material from previous iterations
of the project.

It includes old plans, benchmarks, research, audits, specifications,
experiments, and other superseded project documentation.

These files are intentionally preserved for historical reference. They must
**not** be treated as current product requirements, architecture, roadmap, or
benchmark results.

A fresh audit and planning process will establish the new source of truth.
